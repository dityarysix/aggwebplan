# Catatan Sepekan

Your own column. Each file in this folder is one column (`.md` files only).

How to publish a new column (all in the GitHub website):

1. Open this folder on GitHub and click **Add file → Create new file**.
2. Name the file like `2026-11-27-judul-singkat.md` (date, then a few words, no spaces).
3. Copy the contents of `_contoh.md` into it and replace the text with yours.
4. Click **Commit changes**. The column is on jatimsepekan.com in about 3 minutes.

Header fields (between the two `---` lines):

- `judul`: the title.
- `tanggal`: publication date, `YYYY-MM-DD`. A future date keeps the column hidden until that day.
- `penulis`: your name as it should appear.
- `gambar`: optional, the web address of a photo (leave empty for none).

Files whose name starts with `_` (like `_contoh.md`) are never published.
To unpublish a column, delete its file.
